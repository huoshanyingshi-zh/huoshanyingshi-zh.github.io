关于「火山影视」这个站

火山影视不是聚合站，也不做资源搬运。这里是一份人工维护的观影索引：挑片、写一句真实的观感、标清楚时长和适合的场景，让你少在封面图里挑三分钟。

站点只有一个页面，所有栏目通过锚点切换，手机上同样是一屏一屏读下去的节奏。没有弹窗、没有强制下载、没有第三方追踪脚本，打开即走。

片单会随看随补，想找某一类片子可以在索引栏筛选；如果你有那种「说不清名字但就想要这种感觉」的片，欢迎通过下方地址告诉本站。

这个地址就是官网吗？

是。火山影视目前只在 GitHub Pages 上运行，官方地址就是 https://huoshanyingshi-zh.github.io，没有其他镜像、没有备用域名，遇到长得像的站都不是本站。

手机上能正常看吗？

整站按移动端优先写的样式，导航会自动收成抽屉菜单，卡片和片单行会自动折行，不需要缩放。横屏、刘海屏、平板都做了适配。

片源在哪里？

本站是观影索引与推荐，不直接托管任何音视频文件。每部片子只给类型、时长、观感标签和所属栏目，具体播放渠道以你所在平台的检索结果为准。

多久更新一次？

没有固定排期，看完觉得值得留的就加进索引。剧集栏目标的是真实更新进度，完结与否一眼能看见。

为什么只有一个页面？

少一层跳转，就少一层失效链接。单页 + 锚点的结构对搜索引擎也更干净：一个 URL、一份标题与描述、一套完整内容，收录和排名都不用靠堆页面凑。
